How it works

Install once. Use it directly on YouTube.

The extension adds its own comment section below eligible YouTube videos. These are independent comments and are not part of YouTube's native comment system.

FAQ

Good to know.

Are these original YouTube comments?

No. The extension provides an independent comment system for videos where YouTube's built-in comments are disabled.

Why is Google sign-in used?

Google sign-in is used to support secure accounts, comment ownership, spam prevention, and notifications. Your Google password is not shared with the extension.

Does the extension change the video?

No. It adds a separate interface below the video page and does not alter the video itself.
